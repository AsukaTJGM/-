# 淘宝双11「淘金币赛车-做任务赚能量」电脑端全自动脚本

基于 **Python + 无线 ADB + RapidOCR** 的淘宝大促全自动做任务工具。

免 Root、手机免装任何第三方 App，通过电脑端 AI 视觉识别屏幕文字与按钮，全自动完成大促互动会场的浏览、搜索与秒领任务。

---

## 🌟 核心特性

1. **AI 视觉精准认字（RapidOCR）**：
   * 基于离线 ONNX 视觉模型，自动识别屏幕上的“去完成”按钮及对应的任务名称；
   * 自动过滤复杂的“省钱考试答题”、“拍立淘调用相机”等不可控任务。
2. **多类型任务自适应调度**：
   * **⚡ 点击即领类**（如蚂蚁森林、支付宝农场、闪购等）：自动跳转唤起，2.5 秒后秒级返回，自动处理小程序授权弹窗。
   * **🔍 搜索浏览类**（搜一搜你心仪的宝贝）：自动识别搜索发现/历史搜索标签并点击，进入商品搜索结果页进行 18 秒往复滑动，双层智能退回。
   * **📱 纯浏览类**（好物沉浸看、随心逛）：根据任务要求自适应识别 15 秒 / 5 秒时长，自动执行双向活跃往复滑动（下滑 2 次回滑 1 次），防止滑到底部倒计时暂停。
3. **完全不抢占电脑鼠标**：
   * 指令直接注入安卓内核输入子系统，投屏窗口最小化甚至关闭均不影响脚本运行，电脑可正常工作、娱乐。
4. **智能翻页循环**：
   * 当前屏幕可见任务刷完后，自动向下滑动列表加载新任务，直到全部做完。

## 🛠️ 环境准备与快速上手

### 1. 电脑端安装依赖
需要安装 Python 3.8+ 及 RapidOCR：
```bash
pip install -r requirements.txt
```

### 2. 手机开启无线调试
1. 手机打开 **「设置」** $\to$ **「开发者选项」**；
2. 开启 **「无线调试」**（并建议开启 **「禁止权限监控」** 后重启手机）；
3. 确保手机和电脑连接**同一个局域网 Wi-Fi**。

### 3. 连接手机与启动投屏
在解压好的 `scrcpy` 目录中打开终端：

* **首次配对**（若尚未配对）：
  ```cmd
  adb pair 手机IP:配对端口
  # 根据提示输入 6 位配对码
  ```
* **连接与投屏**：
  ```cmd
  adb connect 手机IP:连接端口
  scrcpy --no-audio -m 1024
  ```

### 4. 运行自动化脚本
1. 在手机上打开淘宝，进入双11赛车页面，停留在 **【做任务赚能量】** 弹窗；
2. 在电脑项目目录下运行：
   ```cmd
   python tb_auto.py
   # 或者指定运行任务数，例如只跑 10 个：
   python tb_auto.py 10
   ```
   也可以直接双击运行 `run.bat`。
