## 🌟 核心特性与优势

1. **🖥️ 独立桌面图形软件（免安装即用）**：
   * 采用现代化 Tkinter GUI 界面，内置编译好独立的 `TaobaoDouble11Auto.exe`；
   * 内置 ADB 与 Scrcpy 投屏组件，开箱即用，告别繁琐的命令行操作。

2. **🔕 Windows 零控制台静默黑科技**：
   * 所有底层 ADB 交互指令全量注入 `STARTUPINFO` 与 `SW_HIDE (0x08000000)`；
   * **运行全程 100% 绝不弹任何黑色的 CMD 窗口**，任务栏无任何闪烁跳动，电脑可同时正常办公、追剧、打游戏。

3. **📱 内置一键手机投屏监视**：
   * 软件内置 `scrcpy 5.0.1` 极速高清投屏引擎；
   * 点击界面上的 **【📱 打开投屏监视】**，秒级唤起手机实时低延迟画面，直观观察任务执行进度。

4. **🧠 AI 视觉文字识别（RapidOCR ONNX）**：
   * 本地离线高精度 OCR 模型，自适应手机屏幕分辨率与淘宝动态排版；
   * 自动过滤大标题干扰，精准拾取真实的推荐搜索词标签；
   * 严格区分 **15秒长浏览** 与 **5秒短浏览**，执行真人级双向往复滑动（下滑 2 次回滑 1 次），确保打满能量计时器。

5. **🛡️ 状态熔断与已结任务防死循环**：
   * 正则匹配 `(10/10)`、`(5/5)` 满额状态；
   * 严格剔除带“已”字（`已完成`、`已领取`）的灰色禁用按钮，杜绝重复无效点击。

6. **🎁 里程碑累计大奖自动领**：
   * 每次回到主面板，自动检测并一键点击顶部亮起的 **【立即领取 +1000】**、**【立即领取 +2000】**、**【立即领取 +4000】** 里程碑能量大奖。

7. **🎛️ 灵活自由的任务过滤面板**：

## 📖 新手保姆级使用教程

### 第一步：手机开启无线调试（只需配置一次）

1. 确保手机和电脑连接在**同一个 Wi-Fi 路由器下**（局域网互通）；
2. 手机打开 **「设置」** $\to$ **「关于手机」** $\to$ 连续快速点击 **「版本号」** 7 次，开启开发者模式；
3. 进入 **「设置」** $\to$ **「系统设置 / 其他设置」** $\to$ **「开发者选项」**：
   * 开启 **【开发者选项】**；
   * 开启 **【USB 调试】**（如系统有“禁止权限监控”，建议一同开启）；
   * 开启 **【无线调试】**，点击进入无线调试详情页。

> 💡 **小贴士（关于首次配对）**：  
> 若手机与电脑此前未建立过无线信任，进入“无线调试”页面点击“使用配对码配对”，获取 6 位配对码和配对端口，在终端中执行一次 `adb pair 手机IP:配对端口` 即可永久免配对。

---

### 第二步：启动软件与连接手机

1. 直接双击桌面上的快捷方式 **【淘宝双11自动化助手】**（或打开 `TaobaoDouble11Auto` 文件夹中的 `TaobaoDouble11Auto.exe`）；
2. 查看手机“无线调试”页面显示的 **IP 地址和端口**（例如：`192.168.1.104:33821`）；
3. 在软件界面上的 **【无线连接】** 输入框填入该地址，点击 **【一键连接无线】**；
4. 状态栏显示 **`● 状态: 已连接 (192.168.1.104:...)`** 即代表通信成功！

---

### 第三步：打开投屏与开始自动做任务

1. 点击界面上的 **【📱 打开投屏监视】** 按钮，电脑会立即弹出一个低延迟的手机镜像窗口（可最小化或拖到屏幕一角）；
2. 在手机（或投屏窗口）上打开淘宝，进入双11赛车活动主页，点击 **【做任务赚能量】** 停留在任务列表弹窗；
3. 在软件界面按需设置：
   * **最大任务次数**：默认 40 次；
   * **任务过滤勾选**：
     * ☑️ **跳过考试答题**（建议勾选，避免答错题）
     * ☑️ **跳过邀请好友**（建议勾选，避免唤起好友分享）
     * ☑️ **跳过下单充值**（建议勾选，避免花钱任务）
     * ⬜ **跳过小程序跳转**（如果不介意跳支付宝农场/庄园，保持不勾选；若只想纯浏览，打勾即可）
   * **自定义额外跳过词**：如填入 `拍立淘, 办卡` 等；
4. 点击界面右侧的 **【▶ 启动全自动任务】** 按钮，助手将全面接管并自动完成全部任务！
5. 过程中如需临时接管手机，随时点击 **【⏹ 停止运行】** 即可优雅终止。

## 🛠️ 常见问题排查 (FAQ)

### Q1: 启动软件时提示“未连接设备”或点击连接失败？
* **检查网络**：确保手机和电脑处于同一个 Wi-Fi（部分路由器开启了“AP 隔离”或连接了访客 Wi-Fi 会导致无法互通）；
* **检查端口变动**：安卓系统的无线调试每次关闭再开启后，**端口号都会随机发生变动**。连接前请确认手机“无线调试”页面显示的最新端口，重新填入后点击连接；
* **尝试有线**：若无线网络复杂，用 Type-C 数据线连电脑并开启“USB 调试”，软件会自动识别有线设备。

### Q2: 任务跑着跑着停了，提示“画面未识别到文字”？
* 手机可能由于长时间无触摸而自动熄屏。软件已内置点亮屏幕逻辑，但建议在手机开发者选项中开启 **【充电时不锁定屏幕】**。
* 确保手机淘宝当前停留在 **【做任务赚能量】** 弹窗上。如果误触退出了该面板，手动点开它即可自动恢复。

### Q3: 杀毒软件（如火绒、360、Windows Defender）会误报吗？
* 本程序使用标准的 Python + ADB 内核开发，绝不含任何恶意代码、不释放 `.vbs` 隐蔽脚本，源码完全公开开源。
* 如有安全软件拦截 ADB 的端口网络访问，请点击“允许”或将本软件目录加入信任区。

## 💻 开发者源码编译与调试指南

如果你希望自行修改源码或重新编译打包，请按以下步骤操作：

### 1. 搭建本地开发环境
```bash
git clone https://github.com/AsukaTJGM/-.git
cd -
pip install -r requirements.txt
pip install pyinstaller
```

### 2. 本地直接运行 Python GUI
```bash
python app_gui.py
```

### 3. 一键编译为独立免安装 EXE 软件
项目根目录已附带自动化清理与同步打包脚本：
```bash
python build_exe.py
```
打包脚本会自动完成以下动作：
1. 清理以往的旧编译缓存；
2. 运行 PyInstaller 将 RapidOCR ONNX 模型与 Tkinter 界面打包为 `--noconsole` 静默程序；
3. 自动注入 `adb.exe`、`scrcpy.exe` 以及全部动态链接库；
4. 自动全量同步至桌面 `TaobaoDouble11Auto` 目录中。
